**For handwritten field sheets, choose Complete.** Download and run the EXE, allow installation to finish and open BoreholeDesk from the Start menu. No GitHub account, separate Python installation or administrator account is required. The small installer obtains and verifies the selected components automatically; the figures above are the total download. Prepared local readers work offline. Choose **File > Open example project** for a first walkthrough.

## Included tools

- Field documents, OCR and handwriting assistance, with review before applying text to log intervals.
- Core photographs, calibrated RQD, core recovery and borehole logs.
- Geological sections, calibrated scan digitizing, site plans and investigation-location import.
- Foundations, piles, lateral profile load tests, subgrade response and earth pressures.
- Rock-mass classifications and strength, stereonets, rock kinematics and slope stability.
- Measured geophysical logs, depth comparisons with SPT/CPT/UCS, site-specific fits and reviewed digitizing of plotted curves.
- PDF reports, vector section exports, English user documentation and calculation references.

This is an initial Windows x64 preview. Review readings, measurements, interpretations and engineering inputs against their sources. The installers are unsigned; keep Windows security protections enabled. This release does not provide a macOS installer.
