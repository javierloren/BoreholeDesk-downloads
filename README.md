# BoreholeDesk

Free Windows desktop software for geological field records, borehole logs,
geotechnical analysis and reports.

**For the field-notebook workflow, choose Complete.** Run the downloaded EXE and
open BoreholeDesk from the Start menu. Python, a Roboflow account and administrator
rights are not required. The installer obtains and verifies its selected
components automatically. Once prepared, local readers work offline.

## Included tools

- Field documents, OCR and handwriting assistance with review before applying data.
- Core photographs, calibrated RQD, core recovery and borehole logs.
- Geological sections, calibrated scan digitizing, source comparison and interpreted units.
- Site plans, investigation-location import and sample records.
- Engineering worksheets for foundations, piles, earth pressures, subgrade response,
  rock mass classification, stereonets, rock kinematics and slope stability.
- Measured geophysical logs, depth comparisons with SPT/CPT/UCS and site-specific fits.
- Rock-mass deformation modulus using Hoek-Diederichs (2006), with parameter references and sensitivity curves.
- Hoek-Brown rock-mass compression strength and Barton JRC-JCS joint peak resistance with method references.
- PDF reports, vector section exports and calculation references.

This is an initial preview. Review readings, interpretations and engineering
inputs before using the results. The installers are unsigned; keep Windows
security protections enabled.
