# BoreholeDesk

Local desktop tools for reviewed geological and geotechnical field records, borehole logs and reports.

**[Download for Windows](https://github.com/javierloren/BoreholeDesk-downloads/releases)** · [User guide](USER_GUIDE.md) · [Methods and data checks](QUALITY.md)

## Get started

1. Open Releases and download the latest preview's `setup.exe` asset.
2. Choose **Quick trial** (about 0.72 GB total) or **Complete** (about 4.42 GB total,
   with all readers prepared for offline work).
3. Open BoreholeDesk and choose **File > Open example project**, or create your own.

Python and the selected engines are prepared automatically for your Windows user.
Handwriting readers can be added later from the program. No shared API key or
Roboflow account is required for local processing. Both choices use the same models.
See the user guide for a local Packages folder and installation without internet.
GitHub's `Source code (zip)` archive contains this repository, not the Windows installer.

## Modules

- Projects, boreholes, lithology, samples, core recovery and RQD.
- Scanned field sheets and handwriting assistance with reviewed transcription.
- Core photographs, physical calibration, depth blocks and local RQD segmentation.
- Stratigraphic logs, geological sections, locations and data exchange.
- Geotechnical calculation tools, rock mass classifications and slope analysis.
- PDF/HTML reports, data checks and a starter EN/ES technical glossary.

## Working with field data

Review transcriptions beside the original field sheet, calibrate core photographs
using measured row lengths, confirm depth blocks and apply the reviewed data to
the borehole. The same project data support logs, sections and reports.

This preview is available for use and feedback. Windows can display an
unknown-publisher notice for this unsigned installer. Check the official download
source and published SHA-256; keep Windows security protections enabled.
