# Reporting a security issue

Use **Security > Report a vulnerability** in this repository for a private report.
Include the application version, Windows version, affected function and steps
to reproduce with synthetic data. Keep API keys, private field records,
photographs and project files out of reports.

For ordinary functionality questions or software faults, use
[Issues](https://github.com/javierloren/BoreholeDesk-downloads/issues).
Review diagnostic files before attaching them.
