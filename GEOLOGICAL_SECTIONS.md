# Geological sections

Open **Geological sections** from Tasks, View or Data. Existing saved sections
also appear in the project explorer. Start with the user's boreholes; the app
does not insert demonstration data into a new project.

## Create a section

1. Use **New**, enter a name and select a view mode.
2. In **Boreholes / order**, check at least two boreholes. Move up/down sets their
   order. The spatial path passes through every selected collar in that order;
   this version does not project nearby/off-path boreholes onto a straight line.
3. Use **Preview changes**. Zoom, fit and scroll controls work on the section.
4. Add interpreted contacts if useful, then **Save section** and **File > Save**
   to retain the section in the project JSON.

**Depth comparison** aligns columns at drilled depth zero, with schematic column
positions 0, 1, 2, etc. These are not metre distances; collar elevations are not
invented. This mode also permits comparison of drilled depths from inclined holes
without claiming they represent vertical depth.

**Spatial section - vertical holes** requires an explicit project CRS/local
grid, X/Y coordinates confirmed in metres, collar Z elevations in metres with a
common named vertical datum, and each selected hole recorded as vertical
(inclination 90 degrees). Set project CRS in **Data > Project properties** and
collars/inclination in **Data > Borehole properties**. No reprojection is applied.
Known EPSG:4326/4269/4258 geographic coordinates are rejected as metre distances.

The horizontal axis is cumulative planar distance along the selected collar
chain, including bends. Elevations use collar Z minus the recorded depth. **VE**
is the vertical-to-horizontal scale ratio; 1 means equal metric scales. Column
widths are symbolic, not material body widths. Collar-to-collar topography and
geological continuity are not inferred.

## Interpret contacts

**Move selected vertex** lets you select a coordinate
row and click its replacement position in the preview. Neighbouring vertices
cannot be crossed. The change resets geological review and does not edit the
source boreholes. This is click-to-reposition, not continuous dragging or undo.

Use **Interpreted contacts > Add contact**, enter a label and choose a color.
**Draw vertices** lets clicks on the preview add points; alternatively use
**Add vertex** and edit the coordinate table. Spatial coordinates are chain
distance/elevation. Comparison coordinates are column position/drilled depth.
Vertices must progress left to right. Edit or remove rows to revise a contact.

Contacts appear as dashed lines with vertex marks. Observations remain solid
borehole columns with the saved material colors/patterns; unexplained intervals
remain blank. A new contact with fewer than two vertices is not drawn and cannot
be saved. No contact is generated by matching lithology names.

Check **Contacts reviewed against the current collars and logs** before saving
an interpretation. Draft edits reset that check. Save stores the independent
contact data and a source-basis hash, not changes to lithology intervals.

Changing the coordinate mode asks before clearing contacts, since a depth/column
coordinate cannot be silently reinterpreted as an elevation/metre coordinate.
Changing the source collars, logs or coordinate basis marks an existing
interpretation for review. A contact extending beyond a changed section path
requires correction rather than being silently cropped.

## Digitize a scanned section

In a **Spatial section**, use **Interpreted contacts > Digitize scanned section...**.
Open a local image or PDF and select the source page. The existing document reader
also supports multipage TIFF. Files are limited to 25 MB and 50 pages.

1. Pick the upper-left and lower-right intersections of a known coordinate grid.
   Use a straight, axis-aligned scan with at least 5 preview pixels between the
   references on each axis. Correct rotation, skew and perspective before importing.
2. Enter the station and elevation at both references in metres. Station zero
   must correspond to the first borehole in the selected collar chain; elevations
   must use the section's vertical datum. A seismic time axis cannot be entered as
   an elevation axis without a separately established time-to-depth conversion.
3. Pick at least two vertices of the interpreted contact inside the calibrated
   rectangle. Use **Pan / inspect** and the zoom controls to inspect the source,
   **Undo last vertex** to correct a pick, or **Clear picks** to recalibrate.
   Changing the source page resets picks and calibration values.
4. Choose **Add contact for review**. Review the resulting vertices against the
   boreholes, confirm **Contacts reviewed against the current collars and logs**,
   then save the section and project. Cancel leaves the section unchanged.

The mapping uses independent linear scales on the two image axes, preserving any
known difference between horizontal and vertical scales. It does not extrapolate
beyond the reference rectangle, infer geological continuity or adjust borehole
logs. Stations must be distinct and remain within the section path. Picking error
depends on image resolution and calibration span; coordinate decimals are not a
statement of survey accuracy.

Each contact has an editable **Source** reference. A digitized contact records the
original filename, page, SHA-256, preview dimensions and calibration references.
The section PDF/SVG identifies source documents; the complete reference remains
in the project. A bounded PNG preview of the calibrated rectangle is embedded in
the project for comparison after reopening. Keep the original file alongside the
project; the original document is not embedded. Manually edited vertices remain interpretations of the
named source, rather than unmodified measurements from it.

## Source comparison and interpreted units

Use **Source image** to show or hide the saved reference preview under the
section drawing. **Unit colors / patterns** independently shows or hides
interpreted fills. **Expand view** temporarily hides the editor to enlarge the
preview; **Show editor** restores the same draft. Zoom and pan remain available.
Preview the selected combination, review and save it to use
the same display in PDF/SVG exports and complete reports. **Remove source image**
removes the embedded preview while retaining contacts and their source references.
Digitizing another source asks before replacing the existing reference image.
The image must use the section's station origin, vertical datum and collar-chain
basis; a display overlay does not establish that correspondence automatically.

In **Interpreted units**, use **Add unit**, give the unit a label and select its
upper and lower contact by their unique names. Set a `#RRGGBB` color and choose a
pattern. Color and pattern are user interpretations. These are the same
BoreholeDesk schematic renderings referenced to FGDC-STD-013-2006 section 37 used
for lithological logs.

The fill uses only the contacts' common station interval, with linear
interpolation between entered vertices. Crossed/reversed boundaries, overlaps
and missing contacts are rejected. An explicit zero thickness at an endpoint may
represent a pinch-out. Unrepresented faults, folds or disconnected bodies must
be modelled as separate bounded interpretations; the editor does not infer them.
Changes reset the review confirmation. Source borehole intervals remain unchanged.

## Outputs and compatibility

- **Export section PDF/SVG** exports the saved section as vectors.
- Complete borehole reports include saved sections containing that borehole;
  their pages are included in the same full PDF preview/export.
- If later metadata changes make a saved section unavailable, the field report
  states the reason and continues to export the available borehole data.
- Sections, contacts, vertices, view mode and references round-trip in project
  JSON. Older projects without a sections field still load normally.
- Working-page navigation preserves section drafts. Section selection/new
  operations protect unapplied edits; deleting a section asks for confirmation
  and keeps the borehole logs.

## Coordinate and interpretation scope

The section editor supports vertical-hole chain sections and non-spatial depth
panels. Map-based path picking, off-path projection, inclined/deviation-survey
trajectories, surveyed topographic surfaces, area fills and automatic correlation
are not implemented. The approved classic Qt interface is retained.
